# ApproveFlow

A lightweight business process approval workflow application.

## Purpose

ApproveFlow provides a structured and traceable workflow for submitting, reviewing, approving, rejecting, and processing business requests.

The project is being developed as a practical software engineering and DevOps demonstration.

## Core Workflow

Requester → Approval → Finance → Processing
